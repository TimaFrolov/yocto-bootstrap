This project is the build instructions for [Yocto](https://www.yoctoproject.org/) in environment provided by [live-bootstrap](https://github.com/fosslinux/live-bootstrap).

# Live bootstrap

The instructions were tested on the commit `1f272f90504871ed5b39af4ae2c7c9aed8a56dbb`. They may work on the newer versions, but it may require slight adjustments.

From now on, commands should be run in the environment generated by live-bootstrap.


# Setting up environment

```bash
export PKG_CONFIG_PATH=/usr/lib/i386-unknown-linux-musl/pkgconfig
```

# Buildroot

## Dependencies

### wget

https://ftp.gnu.org/gnu/wget/wget2-2.1.0.tar.gz

Installation:
```bash
autoconf
./configure --with-ssl=openssl prefix=/usr
aclocal
make
make install
ln -s wget2 /usr/bin/wget
# Without this wget wouldn't be able to find CA certificates and therefore would refuse to download https links. 
mkdir -p /usr/etc
printf 'ca_certificate=/etc/ssl/certs/ca-certificates.crt' >/usr/etc/wget2rc
```

### cpio

https://ftp.gnu.org/gnu/cpio/cpio-2.15.tar.gz

```bash
autoconf
./configure
make
make install
```

### rsync

https://download.samba.org/pub/rsync/src/rsync-3.4.0.tar.gz

```bash
autoconf
./configure --disable-xxhash --disable-lz4 --disable-zstd # since they are not installed
make
make install
```

### unzip

ftp://ftp.info-zip.org/pub/infozip/src/unzip60.tgz
```bash
cp unix/Makefile .
make linux
make install prefix=/usr
```

### flock

https://codeload.github.com/util-linux/util-linux/tar.gz/refs/tags/v2.40.2

```bash
./autogen.sh
./configure --prefix=/usr --disable-liblastlog2
make flock
cp flock /usr/bin/
```

## Configuration

https://codeload.github.com/buildroot/buildroot/tar.gz/refs/tags/2024.11.1

The config for buildroot is in the `buildroot.config` file.

Apply all patches from `buildroot-patches` on the buildroot itself
Copy the `buildroot-global-patch-dir` into the `/buildroot-global-patch-dir` on live-bootstrap filesystem

## Building

```bash
export FORCE_UNSAFE_CONFIGURE=1
export HOST_CFLAGS="-march=i686"
export HOST_LDFLAGS=-latomic
make # V=1 for verbose output
```

## Preparing chroot

```bash
tar -xvf output/images/rootfs.tar -C /glibc-rootfs/
mount --bind /dev /glibc-rootfs/dev
mount --bind /proc /glibc-rootfs/proc

# Statically linked host tools that are better than those provided by busybox
# (busybox versions of these tools are not accepted by Yocto)
unlink /glibc-rootfs/usr/bin/patch
cp /usr/bin/tar /usr/bin/sed /usr/bin/patch /glibc-rootfs/usr/bin

# Locales
cp -r output/host/i686-buildroot-linux-gnu/sysroot/usr/share/i18n /glibc-rootfs/usr/share/i18n

# wget ssl setup
unlink /glibc-rootfs/etc/resolv.conf
cp /etc/resolv.conf /glibc-rootfs/etc/
cp /etc/ssl/certs/ca-certificates.crt /glibc-rootfs/etc/ssl/certs/
echo "ca_certificate=/etc/ssl/certs/ca-certificates.crt" >>/glibc-rootfs/etc/wgetrc

chroot /glibc-rootfs /bin/bash

# Locales
cd /usr/share/i18n/locales
mkdir -p /usr/lib/locale
localedef -i en_US -f UTF-8 en_US.UTF-8
ln -s iconv_prog /usr/bin/iconv

# Link shared libraries so ld can find them
for x in /lib/*.so*; do ln -s $x $(echo $x | sed 's,\.so.*,\.so,'); done || true
ldconfig
```

# Yocto

## Dependencies

### chrpath

https://alioth-archive.debian.org/releases/chrpath/chrpath/0.16/chrpath-0.16.tar.gz

```bash
./configure --prefix=/usr
make
make install
```

### diffstat

https://invisible-island.net/archives/diffstat/diffstat-1.67.tgz

```bash
./configure --prefix=/usr
make
make install
```

### lz4c

https://github.com/lz4/lz4/archive/refs/tags/v1.10.0.tar.gz

```bash
make CC=gcc
make install prefix=/usr
```

### rpcgen

https://codeload.github.com/thkukuk/rpcsvc-proto/tar.gz/refs/tags/v1.4.4

The `./autogen.sh` has to be run from outside of chroot since there are no autotools in buildroot generated rootfs.

```bash
./autogen.sh
./configure --prefix=/usr
make
make install
```

### pzstd

https://codeload.github.com/facebook/zstd/tar.gz/refs/tags/v1.5.6

```bash
cd contrib/pzstd
make CXX=g++ CC=gcc 
cp pzstd /usr/bin/
```

## Preparing environment and patches

```bash
# At some point yocto needs shutdown group. Usually this is handled by pseudo, but we disable pseudo so we actually need this group on host system.
addgroup shutdown

git config --global --add safe.directory '*'

git clone git://git.yoctoproject.org/poky/
cd poky
git switch --detach ff9ca74e17
```

Apply all patches from `poky-patches` on the poky

## Building

```bash
source oe-init-build-env
bitbake --ui teamcity core-image-minimal
```
